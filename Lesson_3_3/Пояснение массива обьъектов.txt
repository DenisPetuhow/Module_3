В чем ключевые различия и улучшения по сравнению с исходником:
• Используется массив `Address* addresses = new Address[n];`, теперь это массив объектов, а не массив указателей.
• Для инициализации массива определен конструктор по умолчанию `Address()`.
• Для каждого элемента массива вызывается конструктор с параметрами через присваивание.
• `delete[] addresses;` используется для корректного освобождения памяти.
• Код итерирует по массиву, например, `addresses[i].get_output_address()`.
